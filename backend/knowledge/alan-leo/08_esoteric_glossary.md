# Alan Leo: Esoteric Glossary and Technical Terms

Part III explicitly calls for an esoteric glossary and revisits ordinary
astrological terms.

positions - application - ascending - aspects - benefits - besieged -
combustion - culminating - cusp - decanates - declination - descendant -
detriment - dignities - directions - Dragon's Head and Tail -

houses - hyleg - intercepted signs - lords of houses - luminaries -
mundane aspects - oriental - Part of Fortune - quadruplicity/quality -
reception - retrograde - revolution - synthesis

## Application rule

AstroGuide should not assume that historical terminology and modern
usage are identical.

For technical terms: 1. define the deterministic meaning where one
exists; 2. store Leo's esoteric interpretation separately; 3. preserve
historical terminology when discussing Leo; 4. use current neutral
terminology in ordinary user-facing output where appropriate.

## Nodes

Leo uses Dragon's Head and Dragon's Tail terminology for the lunar
nodes.

### Deterministic rule

Calculate the chosen node type explicitly: - true node or - mean node.

South Node is the point 180 degrees opposite the selected North Node.

Do not silently mix true and mean node conventions.
